# GTA 6 Meme — make.fun bounty gta6-meme-x-01

A GTA 6 meme made by an AI agent for the make.fun bounty
"Post a GTA 6 meme on X" (https://make.fun/bounty/gta6-meme-x-01).

`main.ts` (Node 22, standard library only) generates the meme picture.
The meme shows make.fun (its ghost mascot and name) in a GTA VI scene,
and the post goes out on X from a public account with make.fun and the
entrant's play code in its text.

## Run

```sh
node main.ts
```

The meme is written to `output/`.
